# Dataset Description: IOT.csv

## Main Variables
- **UDI**: Unique identifier for each record.
- **Product ID**: Product ID with three quality variants (L for low, M for medium, H for high).
- **Type**: Product type (L, M or H)
- **Air temperature [K]**: Air temperature in Kelvin.
- **Process temperature [K]**: Process temperature in Kelvin.
- **Rotational speed [rpm]**: Rotational speed in revolutions per minute.
- **Torque [Nm]**: Torque in Newton meters.
- **Tool wear [min]**: Tool wear in minutes.
- **Machine failure**: Machine failure indicator (1 if it fails, 0 if it does not fail).

## Machine Failure Modes:
1. TWF — Tool Wear Failure
Trigger Condition: The machine fails when tool wear exceeds a randomly selected threshold between 200 and 240 minutes.

Underlying Logic: Tool wear accumulates over usage time. Once it crosses the threshold, the tool's functionality becomes compromised, leading to failure.

AI Guidance: Monitor the Tool wear [min] value. If it surpasses 200, the probability of TWF rises significantly. For instance, wear at 235 min is highly likely to cause failure.

2. HDF — Heat Dissipation Failure
Trigger Condition: Occurs when the temperature difference between process and air is < 8.6 K, and rotational speed is < 1380 rpm.

Formula:
ΔT = Process temperature [K] - Air temperature [K]
Triggered when: ΔT < 8.6K and Rotational speed [rpm] < 1380

Underlying Logic: Low ΔT and low speed reduce cooling efficiency, increasing internal heat.

AI Guidance: Calculate ΔT and compare with threshold.
Example: Process Temp = 310.1K, Air Temp = 302K → ΔT = 8.1K, RPM = 1300 → HDF likely.

3. PWF — Power Failure
Trigger Condition: Triggered when mechanical power is outside 3500–9000 Watts.

Formula:
Power = Torque [Nm] ×  [Rotational speed [rpm] × (2π / 60)]
Failure if: Power < 3500 W or Power > 9000 W

AI Guidance: Convert Rotational speed [rpm] to [rad/s] and calculate power for each record.
Example: Torque = 4.8 Nm, RPM = 2855 → Power ≈ 1434 W → Failure due to PWF.

4. OSF — Overload Failure
Trigger Condition: Occurs when Tool wear × Torque exceeds the product type-specific threshold:

Type L: 11,000 min·Nm

Type M: 12,000 min·Nm

Type H: 13,000 min·Nm

Formula:
Load = Tool wear [min] × Torque [Nm]
Failure if: Load > Threshold

AI Guidance: Check product Type, compute Load, and compare with threshold.
Example: Type L, Tool Wear = 240 min, Torque = 48 Nm → Load = 11,520 → OSF triggered.

5. RNF — Random Failure
Trigger Condition: Occurs randomly with a 0.1% probability.

AI Guidance: Handle as probabilistic noise. Do not infer based on data features. RNF can be ignored in causal modeling but must be included in outcome tracking.
